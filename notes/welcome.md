# Cloud Pi demo notes

This directory is the default read-only root for the `local_read_text` tool.
Only UTF-8 `.md`, `.txt`, `.json`, `.yaml`, `.yml` and `.csv` files under this
directory can be read; absolute paths, `..` traversal and symlinks that escape
the root are rejected.
