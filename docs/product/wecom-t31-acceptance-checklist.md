> **用途**：pi-dev 落地 t31 后，captain 用本清单逐条判 `pass` / `fail` / `未验证`。**本清单不替代真实会话验收**，只把"怎么判"写死。

## 0. 判定规则（先看，避免把"没做"判成"做对"）

1. **一项一条证据**：每条检查必须附证据（原句、`durationMs`、文件 path:line、命令输出、脱敏 transcript 行）。没有证据 = `未验证`。
2. **`未验证` 不算 pass**：t31 没做的项（如 t25 推送、t27 ack）明确记 `deferred`，不得因为"设计上应该会"判 pass。
3. **只判用户可见行为**：日志里有错误码不算 fail；用户正文出现错误码才是 fail。
4. **文案按原文比对**：§2 的"新文案"必须**逐字**出现（允许前后空白差异），旧文案必须**完全消失**。
5. **真实会话优先**：能发真实企微消息的项（S/G/I 组）以真实 transcript 为准；不能发的用代码/单测证据，但只能判"结构 pass"，不能判"体验 pass"。
6. **不自评**：pi-dev 可以填"自检"，最终判定由 captain/体验评审复核；同一人不能既实现又签 pass。

## 2. 文案替换对照（逐字）

来源：[channel.mjs:26-34](../../src/channels/wecom/channel.mjs)、[channel.mjs:214/281-284](../../src/channels/wecom/channel.mjs)、[text.mjs:28-34](../../src/channels/wecom/text.mjs)。

| ID | 场景 | 旧文案（必须消失） | 新文案（必须逐字出现） | 检查方法 |
| --- | --- | --- | --- | --- |
| C1 | `/stop` 成功 | `已停止当前任务。` | `停了。` | 触发 `/stop`；或 grep 旧串 = 0 |
| C2 | `/stop` 空跑 | `当前没有正在执行的任务。` | `现在没在跑任务。` | 触发空 `/stop` |
| C3 | 被取消 | `任务已取消。` | 不再单独发；只保留 C1 的 `停了。` | 取消场景消息条数 = 1 |
| C4 | 超时 | `处理超时，请稍后重试。` | `这次算太久了，我先停掉。要不要换个短点的问法？` | 构造超时或单测 |
| C5 | 模型失败 | `处理失败，请稍后重试。（<code>）` | `刚才没跑通，再试一次？` | 构造失败；**正文不得带 `（xxx）`** |
| C6 | 空回复 | `（模型没有返回内容）` | `这次没生成出内容，再问一次？` | 构造空回复 |
| C7 | 研究入口（D5） | `研究功能未启用。` | `研究入口还没开。先在控制台建个定时任务，结果我会发给你。` | 触发 `/research` |
| C8 | 超长截断 | `（后续约 N 段内容超出单次回复上限，已省略。）` | `内容太长，后面还有约 N 段没发。要我拆成几条继续发吗？` | 构造截断；N 保留数字 |
| C9 | runId 尾部（D7） | `\n\nrunId: r-…` | **不出现**（Trace 只在日志/API） | 任意回复 grep `runId` = 0 |
| C10 | 分段后缀 | `（续 1/3）` | 保留 `（续 N/M）` | 分段场景检查 |

**判定**：
- 任一旧文案仍在用户可见路径 = **fail**。
- 新文案与上表不完全一致（改字、漏句、加括号）= **fail**（除非 captain 书面同意改文案）。
- C5 的"错误码只进日志"：用户正文出现 `（timeout）`、`（errcode）` 等 = **fail**。

## 3. 禁止出现的内部痕迹（正则）

**扫描范围**：用户可见正文（真实 transcript、单测断言、回复构造函数的输出）。**日志、trace、API 不在范围内**。

| 类别 | 正则（大小写不敏感） | 判定 |
| --- | --- | --- |
| 平台/内部错误码 | `(errcode|errmsg|40058|93006|846605|rate_limited|unsupported_target_type|no_prior_inbound|no_active_run|user_not_allowed|chat_not_allowed|mention_required)` | 命中 = fail |
| 括号里的英文小写码 | `（[a-z][a-z0-9_]{2,40}）` | 命中 = fail（中文全角括号） |
| runId / UUID | `\brunId\b|r-\d{8}T\d{6}|[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}` | 命中 = fail（D7） |
| 客服腔（英文） | `how can i help|how may i assist|as an ai|i'm an ai|happy to help` | 命中 = fail（T2） |
| 客服腔（中文） | `作为 ?AI|AI ?助手|很高兴为您服务|有什么可以帮您|希望这对您有帮助` | 命中 = fail（T2） |
| 原始 id | `chatid=|chat_id=|userid=|open_userid=` | 命中 = fail（证据也按此口径） |

**样例命令**（POSIX shell；Windows 用 `Select-String`）：

```bash
rg -n -i 'errcode|errmsg|40058|93006|rate_limited|unsupported_target_type|no_prior_inbound' src/channels/wecom
rg -n '（[a-z][a-z0-9_]{2,40}）' src/channels/wecom
rg -n '\brunId\b|r-[0-9]{8}T[0-9]{6}' src/channels/wecom/channel.mjs
```

**注意**：命中在**日志字段**里是允许的（如 `log.warn({ code })`），只判拼进 `reply`/`sendSegments` 的字符串。
